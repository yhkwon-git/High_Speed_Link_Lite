# DFT / DFD

## 이미 있는 관측점

| 관측 | 위치 | 용도 |
| --- | --- | --- |
| 트레이닝 상태, mission, soft_rst | `CSR_STATUS` | 브링업이 어디서 멈췄는지 |
| 에러 카운트 | `CSR_ERRCNT` | 불일치 누적. 쓰기는 clear |
| 리페어 설정 | `CSR_REMAP` | 웨이퍼 테스트나 레인 BIST가 찾은 배드 핀을 기록하는 자리 |
| 레인 BIST | `CSR_LANE_BIST` | DQ 레인별 에러, 한 레인만 실패했는지, 실패 레인 번호 |
| CKE | `pin_cke` | RESET과 그 외를 핀에서 구분 |

카운터는 16'hFFFF에서 멈춘다. 고장이 계속될 때 0으로 돌아와 정상처럼 보이지 않게 하기 위해서다.

## 루프백 두 종류

1. `hsl_loopback`은 기어박스 앞의 병렬 루프백이다. 컨트롤러 클럭에서 BIST를 돌린다. `prbs_en`이면 관측 데이터가 PRBS이고, `loopback`이면 체커가 그 값을 기대한다. 핀에서 되돌린 값은 아직 0에 묶여 있다. 호스트 경로에서는 루프백이 켜진 동안 마지막으로 보낸 WR 버스트를 `hsl_phy_top`의 `lb_hold`가 잡고, 다음 RD가 핀을 보지 않고 그 값을 돌려준다. T8은 채널 모델에 다른 값이 있는 컬럼을 읽어 이 경로를 구분한다.
2. 핀 루프백은 직렬화 이후의 경로다. deskew와 스트로브까지 포함한다. E11 다음에 별도 먹스로 둔다. 병렬 루프백 통과를 핀 경로 통과로 말하지 않는다.

## PRBS

다항식은 x^7 + x^6 + 1 이다. 시드 0은 무시하고, 리셋 LFSR은 `7'h5A`다. `parallel_o[0]`이 첫 새 비트다. 시드 0은 LFSR을 0 상태에 묶으므로 받지 않는다. 0과 0을 비교하면 고장이 통과한다.

`prbs_en`이면 TX 페이로드가 PRBS다. `loopback`이 0이면 비교 입력을 0으로 두어 `event_err`가 오르고 `ERRCNT`가 증가한다. 핀 루프백은 이 비교에 들어가지 않는다.

비교점은 DBI 앞의 payload다. 루프백이 켜지면 비교 입력이 PRBS 생성기 출력 그 자체라 항상 일치한다. 이 검사가 보는 것은 PRBS, payload 먹스, 비교기, `ERRCNT` 경로다. DBI, 레인 리페어, TX 프레이머는 이 비교에 들어가지 않는다.

## 레인 BIST

`hsl_lane_bist`는 컨트롤러 호스트 포트로 ACT, (WR col 0 → RD col 0) × 16, PRE를 넣는다. 쓰는 데이터는 PRBS7 워드(시드 `7'h2D`, 버스트마다 32 bit 전진)이고, 같은 시퀀스를 다시 만들어 읽은 값과 비교한다. 비트 i, 8+i, 16+i, 24+i 중 하나라도 다르면 DQ 레인 i가 sticky로 표시된다.

- 한 컬럼만 쓴다. 이 framer는 row와 col을 DQ로 보내므로, 주소를 싣는 레인이 고장나면 주소도 바뀐다. 모든 명령이 같은 주소를 쓰면 바뀐 주소도 매번 같아서 에러가 그 레인에만 남는다. 여러 컬럼을 쓰면 서로 다른 컬럼이 같은 곳에 겹쳐 에러가 다른 레인으로 퍼진다.
- 뱅크 타이밍은 스케줄러가 지킨다. BIST 동안 칩은 호스트의 `cmd_ready`와 `rsp_valid`를 0으로 둔다. 시작할 때 호스트 큐는 비어 있어야 하고 루프백은 꺼져 있어야 한다.
- DBI 핀 고장은 보이지 않는다. DBI를 끄면 송신 쪽은 0을 보내고, stuck-at-1이면 모델이 쓰기 데이터를 반전해 저장하고 읽을 때 다시 반전되어 상쇄된다. DBI와 RED 핀은 경계 스캔 방식의 핀 테스트(4단계)로 본다.

## 스캔

- 상태 소자는 플롭만 쓴다.
- 제어 상태(FSM, 포인터, 카운터)에는 리셋이 없는 플롭을 두지 않는다.
- 리셋이 없는 플롭은 큐와 FIFO의 데이터 배열뿐이다. 별도 `always_ff`에 두고, 유효성은 리셋되는 포인터가 정한다.
- 스캔 체인 삽입은 합성 툴 몫이다. v0.1 filelist에 스캔 랩퍼는 없다.

## 테스트가 이 설계에 쓰는 순서

1. 리셋 해제 후 ID를 읽어 접근을 확인한다.
2. 병렬 루프백과 PRBS로 디지털 데이터패스를 본다.
3. `CSR_LANE_BIST`로 레인 BIST를 돌린다. 한 레인만 실패했으면 그 번호를 `CSR_REMAP`에 쓰고 DRAM 쪽에도 같은 설정을 한 뒤 다시 돌려 PASS를 확인한다.
4. 그다음 채널 트레이닝을 진행한다.

2번은 T8이 본다. 4번의 아날로그 완료는 TRAIN done 펄스로 테스트가 대신한다.
